① 执行后端：从「只记录」切到「真丢包」

这是整套系统最后一道闸。先装护栏 → 预检 → 切换，规则才会真正写进内核 table inet gofw。切换后有 30 秒自动回滚：没点「确认保留」就自动退回监控模式，即使误挡了 SSH 也会自己恢复，不需要人能登进机器。

② Web 登录保护

默认不强制，方便内网调试；代价是任何能访问 18081 的人都能改规则。启用后所有 /api/* 需要登录，密码以 0600 落盘，重启仍生效；启用时会自动给当前浏览器建立会话，不会把自己锁在外面。

④ GeoIP 精度与城市 / ASN 级策略

读取中…
规则字段 geo_city / geo_asn 已可用（逗号分隔、! 取反、尾 * 通配），可在「配置源」YAML 或规则 JSON 里写。当前库是国家/地区级，两列库没有城市/ASN 数据时这些条件不会误命中任何包；导入三/四列库后才真正生效。带这两个条件的规则只在用户态决策层匹配，内核模式会整条跳过下发，不会退化成无匹配器的裸 drop。

⑤ 多机策略同步

用 HMAC-SHA256 签名的策略包在多台机器间同步规则集，签名校验不通过一律拒绝应用。各节点需配置相同的 --sync-secret（或环境变量 GOFW_SYNC_SECRET）。
